# 《编程启蒙：思维与代码》8K 原尺寸购书码海报 20 选

本目录包含 20 张横版购书海报，二维码按用户本次上传图片中的原始像素提取并合成。

- 最终成图：`posters/`
- 20 张总览：`overview.jpg`
- 原始圆形购书码：`assets/purchase-qr-circle-original-270.png`
- 二维码位置与像素级复核：`PLACEMENT-QA.md`

## 统一规格

- 文件格式：无损 PNG
- 画布尺寸：7680×4320（8K UHD）
- 数量：20 张
- 二维码尺寸：270×270px，20 张全部保持原尺寸

海报主体来自原始无二维码 ImageGen 成图，并从 1672×941 一次性确定性放大至 7680×4320。放大过程不重新生成画面、不锐化，也不重新绘制中文、人物或书封。

购书码从本次上传的 900×1572 商品截图中按 `(610, 1268, 270, 270)` 原始裁切，仅保留圆形可见区域。二维码在 8K 底图完成后最后合成，未经过缩放、插值或生成模型重绘。

8K 表示最终画布为 7680×4320；原始栅格画面不会因确定性放大而凭空产生新的真实细节。

`overview.jpg` 只用于对比版式，不能用于判断二维码清晰度或进行扫码测试。检查二维码时，请打开 `posters/` 内单张 8K PNG 并以 100% 比例查看。

当前已验证二维码来源、原始像素、静区、圆形边界、位置及 20 张成图的一致性；真实微信设备扫码尚未验证。
