# 《编程启蒙：思维与代码》8K 适配购书码海报 20 选

本目录包含 20 张横版购书海报。二维码从用户上传的商品截图中原样提取，再逐张匹配海报预留圆的实际直径，避免“大白圆中间只有一个小码点”。

- 最终成图：`posters/`
- 20 张总览：`overview.jpg`
- 原始圆形购书码：`assets/purchase-qr-circle-original-270.png`
- 人工复核记录：`PLACEMENT-QA.md`
- 逐张尺寸与坐标：`placements-8k.json`
- 自动检查结果：`QA.json`
- 文件哈希：`SHA256SUMS`
- 可复现合成脚本：`scripts/recompose-qr.cjs`

## 统一规格

- 文件格式：无损 PNG
- 画布尺寸：7680×4320（8K UHD）
- 数量：20 张
- 最终二维码外圆直径：1000–1704px，按每张版式独立适配
- 1920px 宽预览中的对应直径：250–426px

海报主体来自原始 ImageGen 成图，并确定性放大到 7680×4320。本次修正没有让生成模型重绘中文、人物、书封或二维码。

购书码从用户上传的 900×1572 商品截图中按 `(610, 1268, 270, 270)` 裁切，原始 270×270 RGBA 文件完整保留在 `assets/`。最终合成时，从该原始文件一次性使用 nearest-neighbor（最近邻）放大到每张海报的目标直径，再覆盖原有预留圆；没有双线性、双三次等模糊插值，也没有让 ImageGen 重画码点。

最近邻放大不会增加新的真实细节，但可以让原始像素以硬边方式复制，避免二维码在 8K 画布中缩成小点或因平滑插值变糊。

`overview.jpg` 用于比较 20 张版式及二维码相对大小。扫码测试请打开 `posters/` 内的单张 8K PNG；总览图和聊天缩略图不作为扫码结论。

当前已完成来源、尺寸、边界、像素和位置检查；真实微信设备扫码尚未验证。
