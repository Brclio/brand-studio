# Brclio Logo SVG 交付与核验报告

## 结论

本次只使用用户最后指定的 `1254 × 1254` PNG 作为唯一母版，没有混用此前版本。

- `brclio-logo-exact.svg` 是严格像素一致版。它把母版 PNG 原样封装进 SVG；在 `1254 × 1254` 回渲后，所有像素完全相等，RMSE 为 `0`。
- `brclio-logo-pure-vector.svg` 是纯路径矢量版。它不含 `<image>`、Base64 或外部链接，可作为真矢量文件使用；在母版尺寸回渲后的 SSIM 为 `0.995585`。

“逐像素完全相同”和“完全由可编辑路径构成”是两种不同目标：前者由严格版保证，后者由纯矢量版尽可能逼近。

## 四轮视觉核对

已分别核对整体构图、局部特征和放大差异图，以下关键元素均完整保留：

- 蓝色字母 `B` 的外轮廓、左侧竖边和上下弧面；
- Clio 的侧脸、鼻尖、双唇、下颌、颈部和肩线；
- 闭眼及睫线；
- 五片黄色月桂叶；
- 奶油白发带和内部留白；
- 蓝黄之间的奶油白分隔线；
- 右下角红色卷轴、黄色内卷和白色描边；
- 黄色外形、暖白背景及原图中的细斜线纹理。

未发现结构性错位、缺笔、叶片数量错误、轮廓断裂或颜色区域缺失。纯矢量差异集中在栅格抗锯齿和纹理的亚像素采样。

进一步的区域遮罩复核显示：蓝色 `B`、闭眼、五片叶和红色卷轴与参考源的 IoU 均为 `1`；脸部、发丝、右侧白线与卷轴 ROI 的四色遮罩逐像素相同。黄色大底只有 4 个阈值边缘像素差异，左侧白线只有 7 个阈值边缘像素差异，均不形成可见伪影。`32 px` 与 `64 px` 回渲也未发现元素丢失。

## 使用建议

- 做品牌归档或必须严格一致的视觉复现：使用 `brclio-logo-exact.svg`。
- 需要无位图、可缩放的路径数据：使用 `brclio-logo-pure-vector.svg`。
- 纯矢量版为了保留原 PNG 的纹理和抗锯齿，文件约 `38.7 MiB`；适合作为高保真归档母版，不宜直接作为网页资源加载。传输时可使用约 `3.6 MiB` 的 `.svgz`。
- GitHub 组织头像上传时仍建议使用核准后的 PNG，因为 GitHub 的头像上传与处理流程并不以 SVG 作为可靠的最终显示格式。
