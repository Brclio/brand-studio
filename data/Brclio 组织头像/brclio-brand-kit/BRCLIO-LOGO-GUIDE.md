# Brclio 品牌头像与 Logo 设计说明

> **版本**：1.0 · 2026-08-28  
> **适用范围**：GitHub 组织头像、网站标识、社交媒体头像、文档封面、favicon 与应用图标  
> **品牌母题**：记录 · 叙事 · 使之闻名

---

## 1. 品牌原点

**Brclio** 的精神原型来自希腊神话中的缪斯 **Clio**。她掌管历史、记录与叙事；她的名字也与“庆祝、使之闻名”的词根相关。

这与 Brclio 的内容天然相连：博客不是一次性的表达，而是时间留下的索引；教程与学习笔记不是零散信息，而是可以被他人继续使用的知识；编程文章记录的不只是答案，也记录抵达答案的路径；创作档案让一段工作不被时间冲淡，而能被看见、被理解、被传递。

因此，Brclio 的品牌核心不是“古希腊装饰”，而是一个更当代的承诺：

> **让知识被记录，让创作被看见。**  
> *Record what matters. Make it known.*

Logo 以 Clio 为文化内核，以字母 **B** 为识别锚点，以卷轴般的 **C** 为叙事动作，把“品牌名、记录者与传播行为”压缩进一个适合数字界面的符号。

---

## 2. 核心创意

### 2.1 一个符号，三层阅读

Logo 的设计不是对希腊女神的具象复刻，而是一枚具有多重含义的现代知识徽记。观看顺序分为三层：

1. **第一眼是 B**：建立 Brclio 的名称识别，保证在 GitHub 头像尺寸下仍能快速辨认。
2. **第二眼是 Clio 的侧脸**：由奶油色负空间形成，不额外堆叠人物插画；“记录者”被藏进品牌首字母之中。
3. **第三眼是 C 与卷轴**：B 的下部曲线向外舒展，成为抽象的 C／卷轴，暗示书写、归档、教程与持续展开的叙事。

这种“先识别、再发现、后理解”的结构，让符号在小尺寸时足够直接，在大尺寸时又保留值得回看的细节。

### 2.2 为什么使用负空间

Clio 的侧脸没有作为一个独立人物覆盖在 Logo 上，而是从 B 的内部被“留”出来。负空间对应了历史与档案的本质：记录并非只关乎已经写下的内容，也关乎从时间中辨认被忽略的线索。

它也让人物与字母不再是两个拼贴元素，而成为同一个不可分割的结构：**Brclio 既是容纳知识的容器，也是讲述知识的人。**

### 2.3 视觉性格

整体气质遵循 Esther Design System 的品牌 DNA：

- **温暖但不幼稚**：高明度三色降低技术内容的距离感，古典意象则提供文化厚度。
- **可爱但有品质**：圆润、友好的轮廓适合社区语境；克制的几何结构避免卡通化。
- **手作但不粗糙**：大面积保持扁平清晰，只在高分辨率版本中保留极轻的蜡笔斜线肌理。
- **鲜明但不喧闹**：蓝、黄、红按主次分配，不使用霓虹、玻璃拟态或通用 AI 渐变。
- **有记忆点而非装饰堆叠**：人物、字母、月桂和卷轴共用轮廓，不靠神庙、书堆或复杂希腊纹样说明主题。

## 3. 图形构成与寓意

| 构成 | 视觉角色 | 品牌寓意 |
| --- | --- | --- |
| **蓝色 B 轮廓** | 主体骨架与第一识别层 | Brclio 的名称锚点；稳定、可信、适合知识与技术内容 |
| **Clio 侧脸负空间** | 藏于 B 内部的第二识别层 | 历史、记录与叙事的缪斯；代表观察、整理与讲述 |
| **金黄色月桂** | 贴合人物轮廓的轻量提示 | 庆祝、荣誉与“使之闻名”；不是权威炫耀，而是让好作品被看见 |
| **卷轴／抽象 C** | 下部向外延展的曲线 | Clio 的首字母；书写、知识展开、开放的叙事与可持续档案 |
| **红色印章／卷尾** | 面积最小的视觉句点 | 发布、确认、落款；象征一篇内容从记录走向公开 |
| **暖黄色圆形底** | 图标容器与远距离识别面 | 像太阳、纸张与舞台灯光，为“被看见”提供温暖背景 |

图形重心略偏向人物凝望的方向，使符号带有“向前阅读”的动势；整体仍保持中心稳定，以适应 GitHub 的圆形裁切和浏览器标签页的极小显示面积。

## 4. 色彩系统

### 4.1 核心色板

| 名称 | 色值 | 建议占比 | 角色 |
| --- | --- | ---: | --- |
| **Clio Blue** | `#2B7FD8` | 60% | Logo 主体、标题、链接、主要品牌识别 |
| **Archive Gold** | `#F4D758` | 30% | 圆形底、月桂、重点高亮与温度来源 |
| **Seal Red** | `#E84A5F` | 10% | 印章、卷尾、CTA 与极少量视觉句点 |
| **Parchment Cream** | `#FEFCF6` | 中性色 | 负空间、纸张感背景、浅色界面 |
| **Narrative Ink** | `#1A1A2E` | 中性色 | 正文、深色描边与高对比辅助 |

三色遵循 **60 / 30 / 10** 的主次关系。红色永远是点缀，不应扩张为 Logo 主体或大面积背景。数字界面中避免使用纯黑 `#000000` 与纯白 `#FFFFFF`，以保留温暖、编辑感的视觉气质。

### 4.2 背景适配

- **默认**：优先使用暖奶油色或中性浅色背景。
- **深色界面**：使用完整的黄色圆形容器，不直接把蓝色主体裸放在深色底上。
- **复杂图片背景**：应先加完整圆形底或独立留白区；不可依赖阴影强行分离。
- **单色场景**：仅在印章、丝印、激光雕刻等受限工艺中使用单色版，优先深墨色 `#1A1A2E`。
- **无障碍原则**：用于正文或交互状态时，应单独检查色彩对比；Logo 的装饰色不能代替文字标签。

## 5. Logo、Avatar 与 Favicon 的关系

它们使用**同一份 Logo 几何母版**。Favicon 不是另画一枚相似图标，也不改变人物、月桂或卷轴结构；它只减少外部空白，并从同一母版导出不同像素尺寸。

| 版本 | 主要任务 | 必须保留 | 允许调整 | 推荐场景 |
| --- | --- | --- | --- | --- |
| **完整 Logo／头像** | 讲清品牌故事并形成长期识别 | B、完整 Clio 侧脸与闭眼、5 片月桂、白色分隔线、红黄卷轴 C | 平台需要时调整外部留白与文件压缩 | GitHub 组织头像、社交头像、文档封面、品牌介绍 |
| **Favicon 忠实适配版** | 在 16–32 px 中确认“这是 Brclio” | 与完整 Logo 完全相同的构图、比例、元素数量和色彩关系 | 仅紧凑裁切、缩放算法、压缩与像素重采样 | 浏览器标签页、书签、PWA、快捷方式 |
| **单色标** | 满足受限印刷工艺 | B 与 C 的外轮廓关系 | 取消所有色彩和内层肌理 | 印章、蚀刻、压印、单色周边 |

Favicon 的原则是“**同一母版，尺寸适配，不重画**”。16 px 下细节会自然合并，但这属于显示分辨率的结果，而不是设计师主动删减或替换结构。任何尺寸都不得把 5 片月桂改成 1–2 片，也不得重画 Clio 的额头、鼻、唇、下巴、肩颈或闭眼。

### 5.1 Favicon 的适配方法

本套 favicon 以 `avatar/brclio-logo-master-1254.png` 为唯一视觉母版：

- 从原图中央做正方形紧凑裁切，只减少约 9% 的外围空白；Logo 内部像素和各元素相对位置不变。
- `512／192／64／48／32／16 px` 全部由同一个裁切母版向下重采样，不使用独立重绘的路径。
- `favicon.svg` 是自包含的 SVG 容器，内部嵌入忠实的 512 px Logo 图像；这样既方便现代浏览器引用，也避免重新矢量化造成轮廓漂移。
- `favicon.ico` 包含 16、32、48 px 三个同源图层，不替换月桂、不删除闭眼，也不改写卷轴 C。
- Apple Touch Icon 与 maskable 图标使用完整画布，以保留系统圆角和蒙版所需的安全区。

验收顺序为：**512／192 px 必须与母版视觉一致；64 px 能识别闭眼、5 片月桂与完整卷轴；32 px 保持整体剪影和色彩关系；16 px 允许细节自然合并，但不得出现另一套造型。**

## 6. 尺寸、留白与裁切规范

### 6.1 最小尺寸

- 完整彩色 Logo：数字端最小建议 **48 × 48 px**。
- GitHub／社交头像：建议上传 **1024 × 1024 px**；低于 **64 × 64 px** 时不再评估细纹，只以轮廓识别为准。
- Favicon SVG：首选浏览器资源；为防止重绘漂移，使用自包含的高分辨率母版图像，而不是另造矢量路径。
- Favicon PNG：至少提供 **16、32、48 px**；PWA 另提供 **192、512 px**。
- Apple Touch Icon：使用 **180 × 180 px** 的不透明版本，图形四周约留 **10%** 安全边，交由系统完成圆角裁切。
- 小于 48 px 的场景使用交付的 favicon 导出文件；它与完整头像同源，但裁切更紧、采样针对小尺寸。

### 6.2 安全区与外部留白

定义 `X = 标识画布边长的 1/8`：

- Logo 四周至少保留 **1X** 的独立空间，不放文字、边框、图标或高对比纹理。
- 用作圆形头像时，核心图形应落在画布中央约 **80%** 的安全区内；四角不放关键细节。
- favicon 采用紧凑构图，Logo 外沿保留约 **1.5%** 的技术边；不得继续裁切，也不得让蓝色 B、黄色圆或卷轴触碰画布边缘。
- 与品牌名称横向组合时，图形与字标间距至少 **0.75X**。

### 6.3 裁切

- 不拉伸、不压扁；任何缩放都必须保持 1:1 比例。
- GitHub 会把方形上传图显示为圆形，发布前必须检查圆形裁切。
- 不让月桂、卷轴或红色印章碰到圆形边界。
- 不用截图代替源文件；优先使用交付的 PNG、SVG 或 ICO。

## 7. 正确与禁用方式

### 推荐

- 使用原始配色、固定比例和完整安全区。
- 在浅色与深色 GitHub 界面分别检查头像。
- 在 16、32、48、64 px 四个关键尺寸进行肉眼测试。
- 高分辨率品牌展示保留原有轻微手绘肌理；小尺寸中让肌理自然随重采样减弱，不另画纯色替代标。
- 将红色控制为“落款”，用一小处完成视觉收束。

### 禁止

- 不改变蓝、黄、红的角色，也不把红色扩成主色。
- 不使用蓝紫渐变、青色霓虹、发光、玻璃拟态、3D 金属或厚重投影。
- 不把 Clio 改成写实人像、全身女神或复杂古希腊雕像。
- 不额外叠加神庙、羽毛笔、书堆、星星等说明性符号。
- 不增加、删除或重排月桂；标准 Logo 始终保留原图中的 **5 片**叶子。
- 不删除 Clio 的闭眼，也不改变额头、鼻尖、嘴唇、下巴与肩颈轮廓。
- 不将 Logo 旋转、倾斜、镜像、描边加粗或局部变色。
- 不把 Logo 塞进另一层圆角卡片、盾牌或徽章中。
- 不在复杂照片上直接使用透明版，也不依赖外发光保证可见。
- 不在 Logo 内加入 `Brclio`、网址或标语；文字应在图形外独立排版。
- 不使用纯黑、纯白替换暖奶油色与墨色。

## 9. 网站接入

将 favicon 文件放入网站公共根目录，然后在 HTML 的 `<head>` 中加入：

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon-32x32.png" type="image/png" sizes="32x32">
<link rel="icon" href="/favicon-16x16.png" type="image/png" sizes="16x16">
<link rel="apple-touch-icon" href="/apple-touch-icon.png" sizes="180x180">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#2B7FD8">
```

推荐的网页 Logo 替代文本：

```html
<img src="/brclio-logo.png" alt="Brclio — 记录、叙事与知识创作">
```

如果 Logo 紧邻已经写出“Brclio”的可见标题，为避免屏幕阅读器重复，可使用空替代文本：

```html
<img src="/brclio-logo.png" alt="">
```

浏览器可能缓存 favicon。替换后若未立即显示，可硬刷新、清理站点缓存，或在文件 URL 后短期添加版本号，例如 `/favicon.svg?v=2`。

## 10. 主头像生成提示词（完整版本）

以下为选中头像的完整生成简报，可用于重绘、扩展或向设计师解释目标。若重新生成，应以当前交付图为视觉基准，避免每次生成导致品牌轮廓漂移。

```text
Use case: logo-brand
Asset type: square GitHub organization avatar for Brclio, must remain recognizable at 32–64 px
Input images: Image 1 is a style and color reference only; preserve its warm handcrafted brand feeling and palette, but create a new original mark
Primary request: design one original emblem inspired by Clio, the Greek Muse of history, records, narrative, celebration, and making things known
Subject: a single bold Brclio symbol that combines an unmistakable capital B silhouette with a simplified classical Muse Clio side-profile in negative space; the lower curve unfurls into one clean scroll ribbon suggesting an abstract C and the act of recording history
Style/medium: flat vector-friendly logo rendered as a polished raster image; warm editorial hand-drawn marker and subtle crayon-hatch texture; cute but refined, human, not childish
Composition/framing: perfectly centered square icon, clear silhouette, generous safe margin, circular or softly rounded emblem; one dominant symbol only
Color palette: Esther Design System colors — blue #2B7FD8 about 60%, golden yellow #F4D758 about 30%, red #E84A5F about 10%, warm cream #FEFCF6 and ink #1A1A2E; flat colors only
Materials/textures: very restrained diagonal crayon hatching, crisp outer edge
Text: no words, no small letters, no typography other than the abstract B/C form
Constraints: strong at tiny avatar size; simple geometry; balanced negative space; readable against both light and dark GitHub UI; original design; no watermark
Avoid: realistic human portrait, full-body goddess, ornate Greek temple, many laurel leaves, multiple books or objects, tiny details, thin lines, generic AI logo, blue-purple gradient, cyan, neon, glassmorphism, 3D, mockup, shadow-heavy badge, pure black, pure white
```

## 11. 扁平化修订提示词（完整版本）

该提示词用于锁定已选构图，只修正颜色和材质；不应用来重新设计轮廓。

```text
Use case: precise-object-edit
Asset type: square GitHub organization avatar
Input images: Image 1 is the edit target
Primary request: change only the color treatment so the logo uses clean flat solid fills with no gradients and no glow
Keep unchanged: preserve the exact centered composition, B-shaped blue silhouette, Clio side-profile negative space, laurel placement, scroll-shaped C curl, proportions, generous margin, and overall geometry
Color palette: exact flat blue #2B7FD8, flat golden yellow #F4D758, flat red #E84A5F, warm cream #FEFCF6, ink #1A1A2E only
Materials/textures: retain only an extremely subtle dry crayon hatch inside the large flat blue and yellow areas; outer edges crisp
Constraints: no new elements; no text; no watermark; readable at 32–64 px
Avoid: gradients, lighting effects, glow, 3D, shadows, extra leaves, extra outlines, layout changes, realistic rendering
```

### 后续变体的控制原则

- **先锁定轮廓，再调整介质**：不得让新模型重新解释 B、侧脸和卷轴的位置。
- **一次只改一个变量**：例如只做单色版、只去纹理、只更换背景。
- **锁定已确认母版**：当前以 `avatar/brclio-logo-master-1254.png` 为唯一视觉依据；除非先完成逐路径人工校对，否则不要用 AI 重绘或自动矢量化替换它。
- **所有变体都做小尺寸测试**：至少检查 16、32、48、64 px，并同时放在浅色与深色底上。

## 12. Favicon 忠实适配提示词

严格来说，本 favicon 不需要生成模型：正式生产应直接从已确认母版裁切和缩放。以下提示词只适合交给必须执行适配工作的图像工具或设计师，重点是禁止重画。

```text
Use case: faithful-logo-adaptation
Asset type: favicon and app-icon export set for Brclio
Input image: use the supplied approved Brclio logo as the only visual master
Primary request: adapt the exact supplied logo to favicon sizes without redesigning, redrawing, simplifying, or replacing any internal element
```
