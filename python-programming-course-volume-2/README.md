# 编程思维到 Python · 双卷课程安排

独立静态页面，可直接打开 `index.html`，不依赖构建工具或仓库根目录资源。

## 课程结构

- [Python Programming Course](https://bornforthis.cn/column/Python-Programming-Course/)

页面以源站左侧目录为主要依据，整理为两卷独立课程表：

- 卷一「编程思维」：5 章、32 个课时；
- 卷二「Python 小咖养成」：14 个大纲节点、44 项内容。

所有课时均为非链接大纲项，默认折叠，并使用内容摘要替代上课安排信息。课程数据位于 `assets/course-data.js`，页面无需构建即可直接打开。
