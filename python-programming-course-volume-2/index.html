五段路，从理解计算到写出程序

学习路线依照左侧课程目录的两卷顺序整理：卷一负责“怎样想”，卷二负责“怎样写”。

think clearly, code deliberately.
  1. WHY & HISTORY

    先认识编程为何存在

    卷一第一、二章。 从学习编程的意义出发，沿着早期程序、计算机器与密码破译认识计算思想的来路。

  2. THINKING TOOLS

    学会抽象与推理

    卷一第三章。 从图像、二进制、归纳演绎到图灵测试，理解计算机如何表示、分析并判断问题。

  3. ALGORITHMS

    把方法用于生活难题

    卷一第四章。 用估算、并行、决策、灰度测试、寻路、搜索与推荐等案例建立算法意识。

  4. AI BOUNDARIES

    看清智能的能力边界

    卷一第五章。 围绕知识机器、战争机器人、密码安全与自动驾驶，讨论人工智能的能力、风险与责任。

  5. PYTHON PRACTICE

    进入 Python 基础实践

    卷二完整大纲。 从环境、数据类型进入条件与循环，再用函数、类、文件和异常把思考方式写成程序。

Learning Principle

先学会怎样想，再学会怎样写。
