五段路，搭起一张 Python 全局地图

以下五段是对源课纲的编辑整理，不新增课时，也不改变官方章节顺序。

order matters, speed doesn't.
  1. GET READY

    先让工具就位

    环境搭建与新建项目。 把运行 Python 所需的环境准备好，让后面的每一步都能真正动手。

  2. DATA FOUNDATION

    认识数据的形状

    第一至第四章。 变量、数值、字符串、列表、元组、字典与集合，逐步建立 Python 数据类型的全局观。

  3. CONTROL FLOW

    让程序开始做决定

    第五至第七章。 从布尔与 if 进入“框架式语法”，再用 while 与 for 让逻辑重复、遍历与组合。

  4. ABSTRACTION

    把想法组织成结构

    第八至第九章。 用函数封装重复逻辑，用类理解对象与职责，并通过对话式对战游戏完成综合实践。

  5. ENGINEERING

    收尾、排错与结业

    第十、十一章与结业测试。 让程序能处理文件、面对异常，再用一次完整测试回看基础知识。

Learning Principle

课程没有固定总时长，掌握才是刻度。

源课程特别说明：一个知识单元不等于一堂课就能结束；页面标出的时长来自历史学员平均值，只用于理解内容量，不应被当作速度目标或结果承诺。

01

一节 ≠ 一次课

理解能力、学习状态与具体需求不同，同一知识单元可能需要不同次数的讲解与练习。

02

时长只是历史参考

有明确来源的平均时长会标在课时旁；未标注的部分保持“待定”，不擅自补数字。

03

逻辑训练重于背语法

从 if 开始，数据知识会被装进条件、循环、函数与类这些结构中反复组合。

知识讲解 → 动手练习 / 项目 → 章节测试 → 答案复盘 → 进入下一章

03

别把目录当清单，把它当成练习循环。

这四步是本展示页提供的使用建议：先看主课，再独立动手；测试后再打开答案；项目完成后，把卡住的地方带回对应章节复盘。

  • 01 FOLLOW THE ORDER

    先按顺序走完主课

    数据类型是后续框架语法的材料。基础阶段先保持顺序，避免在概念没有连起来时过早跳章。

  • 02 CODE BEFORE ANSWER

    先写，再看答案

    章节测试用于暴露理解缝隙。先保留自己的思路与错误，再对照答案复盘，学习痕迹才会留下来。

  • 03 BUILD SOMETHING

    把语法装进项目里

    问答式简历、运势预测软件、对话式对战游戏，是三次从“知道”走向“能做”的实践节点。

  • 04 REVIEW THE MAP

    回到全局图复盘

    卡在条件、循环、函数或类时，先判断缺的是数据知识、结构理解，还是把问题拆小的能力。
